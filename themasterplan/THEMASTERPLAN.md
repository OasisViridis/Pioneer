## 1. 愿景与核心定位 (Vision & Identity)

### 1.1 一句话定位

**Pioneer** 是一款**基于「一切皆 UI」理念的模块化 AI Agent 交互系统**。它由两条主线构成——**模块化 AI Agent 交互系统**（媒体库海报墙 + 模块化工作区）与**轻量、可复用的 Harness 工程**（轻量上下文 / 能力模块化 / 统一接入）。它彻底打破市面泛滥的“三栏 Chatbot 聊天框”模式，把项目入口、任务执行与 Agent 运行能力组织到同一套桌面工作环境中，让项目、状态与能力都能在界面中直接看到、直接操作。

**Canonical local checkout:** `D:\Project\GitProject\Pioneer`。

### 1.2 核心理念

- **一切皆 UI (Everything is a UI)**：
  - UNIX/Linux 是一切皆文件；Harness 是一切皆插件；**Pioneer 是一切皆 UI**。
  - 不把配置、工具、状态、日志藏在代码或终端行中，全部实体化为可交互、可编排、用户友好的 UI 组件。
- **双主线架构 (Dual-Track Architecture)**：
  - **主线一 · 交互系统**：Tabs 顶层框架 + 媒体库海报墙 + 模块化工作区（会话 + 按需打开的可停靠面板）；
  - **主线二 · Harness 工程**：轻量上下文 / 能力模块化 / 统一接入，复用 Pi Agent Harness 运行底座。
- **克制原则（Apple HIG 级信息设计）**：
  1. _沉默优先_：界面元素默认静默，无事件时不制造信息噪音；
  2. _渐进披露_：默认胶囊与单行摘要，细节按需展开；
  3. _证明靠对比_：通过执行前后状态对比与意图核对证明 Agent 价值。

## 3. 数媒「四合一」工程交付矩阵 (Four-in-One Deliverables)

| 维度               | Pioneer 落实方案                                                                     | 验收物与论证点                                       |
| ------------------ | ------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| **设计 (Design)**  | 媒体库海报墙 + 模块化工作区（会话 + 按需打开的可停靠面板）+ 克制原则 + Design Tokens | Figma 高保真原型规范库、组件范例、交互 Demo 页面     |
| **技术 (Tech)**    | 显式状态层 + 事件流总线 + Tabs / Dockview 面板系统 + Harness 上下文组装与统一接入    | 完整运行桌面应用、通信管道、事件监听器测试           |
| **内容 (Content)** | 本地项目自动刮削内容模板、任务 Runbook 沉淀、出厂场景演示包、交互提示短句库          | 刮削规则库、Runbook 案例集、开题与毕业论文           |
| **智能 (AI)**      | 目标澄清与风险权限确认（非逐步审批）、轻量上下文策略、能力模块化组合、对比实验       | 意图核对流程演示、上下文用量 / 完成率 / 耗时对比数据 |
