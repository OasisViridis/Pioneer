## 准备

1. 在工作树根目录执行 `$env:ELECTRON_RUN_AS_NODE = $null`，再执行 `pnpm --filter @pioneer/desktop start`。
2. 打开任意一个真实项目，新建会话（建议命名 `narrator-<日期>`）。
3. 按 `Win + Ctrl + Enter` 启动 Narrator。
4. 需要时按 `Caps Lock + F1` 查看 Narrator 键盘帮助。
