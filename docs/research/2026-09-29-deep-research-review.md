## 可保留的研究命题，不是实现承诺

1. **Project-first + 阶段化工作区**：与[选题收敛说明](../../选题收敛说明.md)的交互主线一致；“更易辨认项目、减少认知负担”仍需比较任务、可用性测试和对照界面证明。
2. **Intent → permission → event → evidence**：可作为 M3-B / M4 规格的候选分析框架；每一层都需要数据结构、拒绝/中止/断连路径与真实权限门。不得把一张确认卡等同于执行授权。
3. **Harness 可测量**：可作为 M5 评测设计输入。固定同一模型、任务集、环境和运行预算，对照上下文用量、任务成功率、耗时、工具调用、人工干预及错误写入/恢复；指标采集必须来自真实运行，不用模拟 telemetry。
4. **Proto-Persona 与用户故事**：原稿四个画像可作为访谈招募和任务设计的起点；年龄、职业、痛点、付费意愿及“创意用户优先”的市场落点均尚无 Pioneer 一手证据。
5. **竞品差异化**：不再仅以海报墙、Dock、Diff 或多 Agent 的“有无”作为创新论证；把“最小界面/上下文/权限是否提升审阅与恢复效率”写成**可证伪假设**，而不是既成优势。
