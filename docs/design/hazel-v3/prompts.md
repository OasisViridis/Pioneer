# 素材复现配方

两张 PNG 使用 imagegen，以用户图中的果冻／制服配饰为参考，透明背景生成。以下是整理后的复现配方，不是逐字 API 请求审计记录；输出为独立演绎，不复刻完整立绘。

## Jelly companion

Reference the supplied Hazel imagery for the mint jelly rabbit motif and tiny cherry accessory. Create one small mint-green jelly companion for an understated desktop application empty state: rounded translucent pudding body, two soft rabbit-like ears, tiny dark facial dots, a little cream highlight and restrained berry cherry on top. Gentle gouache / soft illustrated material, muted mint, clean silhouette recognizable at 64–88px. No person, text, logo, surrounding decorations, scene, UI, backdrop or watermark. Isolated subject, genuinely transparent background, transparent padding, soft detail rather than glossy plastic.

## Uniform ribbon

Use the supplied Hazel uniform details for the navy, silver-gray and champagne palette. Create one independent butterfly bow accessory: structured dark navy ribbon, restrained silver piping, small champagne circular pendant. Quiet gouache illustration with crisp silhouette, very limited highlights, suitable for a 48px application about-page motif. No person, full costume, text, official insignia, stars, wallpaper, UI or watermark. Isolated object, genuinely transparent background and padding.
