## 采用的行为

- PR 是 Adobe Premiere Pro。模块是内容，面板是实例，布局由人组合；不恢复专注、审阅、交付分页或模式按钮。
- 结果更新入口与数量，点击才打开/定位面板。不自动切换、抢焦点、重排或滚动。
- Harness 提供目标、能力、上下文与真实反馈，具体解法留给模型。意图摘要用于澄清复杂目标，不是每个任务开始前的必经卡。
- 权限扩大、破坏性动作和对外发布交由人决定；已批准范围不重复审批。原型权限卡仅是具体动作样例，不升级为全局产品门。
- macOS 式三点与窗口逻辑仅补 Windows 窗口层，不覆盖 Hazel × Claude 规范。
- 保留单装饰槽与克制密度。桌宠使用冻结 ZIP 已有的 `public/assets/ref/hazel-jelly.png`，替换同槽示意，不生成新素材；纸蝶复用。将桌宠放在空白处不代表已实现自动避让。
