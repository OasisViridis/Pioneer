## 2. 已采纳的交互与美术语言

**首页找工作区，Tabs 切会话，工作台围绕当前任务组织模块。**

1. 工作区用纵向媒体库海报表示；先选择工作区，再继续或新建具体会话。
2. 顶部只有一排全局会话 Tabs。任务标题优先，工作区标记与状态次之。3–5 个可见会话是注意力目标，不是硬上限；多余会话从可搜索列表恢复。
3. Agent 对话是中心。上下文、能力、文件、Diff、预览按需打开。专注布局保留约 840px 阅读列；审阅/交付把宽幅产物与对话并列。
4. 局部 Tabs 只切换所在产物面板。改变布局不执行任务，不授予权限，不串用其他会话的草稿与内容。
5. 关闭标签不等于删除会话，也不等于停止运行。停止请求、停止确认、断连未知必须不同。
6. 不带 PPT 超大标题，不加时间轴、常驻项目树、常驻历史侧栏、第二排全局导航。`main` 就叫 `main`。

### 可直接执行的状态和组件规则

1. **主动作**继续用藏蓝 `#333C50` + 浅文字；次动作浅面板 + 银灰描边。基础间距维持 4/8/12/16/24/32px、控件圆角约 8px、卡片 10–16px，不新增渐变/玻璃或厚阴影。
2. **运行中**用明确文字、必要时配藏蓝标记；**待用户批准/审阅**用暖通知底 `#EDE4D6`、香槟描边 `#C6AF94` 与深色正文；**已完成**可用薄荷底 `#D7E3DA` 与深色正文；**失败/破坏性**保留风险红 `#B25352` 与明确原因。颜色只是辅助，不能代替状态文字或审批动作。
3. **不要把 `#76614B` 小字直接放在 `#C6AF94` 实心底上**：现有两色约 2.78:1，不满足常规正文 4.5:1。金色宜作细边或点缀；浅暖底上的正文用 `#2C3547`。现有 `#2C3547/#F9FAF7` 约 11.74:1、`#646E72/#F9FAF7` 约 4.99:1、`#F9F9F9/#333C50` 约 10.48:1。
4. 停靠面板里优先展示“现在进行到哪一步 / 需要谁处理 / 输出是什么”。无真实运行器时，只展示空态和可辨认的示例，不声称真实工具调用、Diff 或执行结果。
5. 在 1280×800、1440×900 的桌面工作台保持高信息密度、固定输入区和独立滚动；不从营销网页复制大面积空白。继续只有**一排全局会话 Tabs**，文件/Diff/预览仍是产物面板内部的局部 Tabs。

本节是工作台**设计语言与组件语义**的增补，不改变 Electron IPC、权限、模型、工作区文件或已冻结 M1 原型。实际画面实现仍须依照相应 Contract、Prototype、Real E2E 与人工视觉检查分别验收。
